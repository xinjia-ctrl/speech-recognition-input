## 启动与首次使用

- [ ] 使用 `python -m app` 可以正常启动应用。
- [ ] 首次启动时出现新手引导窗口。
- [ ] 新手引导窗口尺寸适中，不遮挡主要内容。
- [ ] 新手引导可以完成基础配置并进入主界面。
- [ ] 非首次启动时只显示悬浮按钮，不自动展开完整设置面板。
- [ ] 点击悬浮按钮后出现小输入框。
- [ ] 点击设置入口后才展开完整设置面板。
- [ ] 点击悬浮按钮右上角关闭按钮后，悬浮按钮隐藏。
- [ ] 按 `ctrl+alt+space` 可以重新唤醒悬浮按钮。

## 设置页与配置检查

- [ ] 识别模式下拉框可以切换本地、HTTP API、WebSocket。
- [ ] 本地模型大小下拉框显示正常，右侧为箭头图标。
- [ ] API 地址、模型、翻译地址、翻译模型、WebSocket 地址、WebSocket 模型都可以从预设中选择。
- [ ] 鼠标滚轮不会误切换下拉框当前值。
- [ ] API 地址和模型选择不匹配时，配置检查区域给出提示。
- [ ] HTTP API Key、WebSocket API Key、翻译 API Key、AI 润色 API Key 输入框以密码形式显示。
- [ ] 点击保存设置后有明显按钮反馈。
- [ ] 保存后重启应用，设置仍能正确加载。
- [ ] `config/settings.json` 不会被 Git 跟踪。

## 本地识别模式

- [ ] 安装本地依赖后，本地模式可以启动识别。
- [ ] 点击悬浮按钮开始录音，按钮状态变为录音中。
- [ ] 再次点击悬浮按钮停止录音。
- [ ] 3 秒普通话短句可以识别并显示在预览输入框。
- [ ] 10 秒普通话句子可以识别，不出现界面卡死。
- [ ] 无有效声音时只提示“本次没有识别到声音”，不弹出必须手动关闭的错误框。
- [ ] 本地识别结果默认输出简体中文。
- [ ] 规则后处理可以去掉常见口头语，例如“呃”“那个”“这个”。
- [ ] 词典校正开启后，常见错词能被修正。
- [ ] 关闭规则后处理后，识别结果不再自动清洗口语。

## HTTP API 一次性识别模式

- [ ] 选择 HTTP API 模式并填写地址、模型和 API Key。
- [ ] 使用百炼预设时，地址为 `compatible-mode/v1/chat/completions`，模型为 `qwen3-asr-flash`，配置检查提示匹配。
- [ ] 百炼 HTTP API 已填写 `websocket_api_key` 时，可以复用该 Key 完成云端识别，不会因为 `api_key` 填了其他服务商 Key 而触发本地兜底。
- [ ] 使用硅基流动或其他预设时，地址和模型提示匹配。
- [ ] 录音结束后，音频被一次性提交到云端识别。
- [ ] 云端返回文本后，预览输入框显示识别结果。
- [ ] 开启“API 失败本地兜底”后，云端地址或 Key 错误时会自动切换到本地模型。
- [ ] 关闭“API 失败本地兜底”后，云端失败只显示错误提示，不会自动跑本地模型。
- [ ] API Key 错误时，界面只显示脱敏后的错误信息。
- [ ] 网络失败或接口不可用时，不弹出必须点击 OK 的阻塞错误框。
- [ ] HTTP API 模式不会误显示为本地离线模型。

## WebSocket 实时识别模式

- [ ] 选择 WebSocket 模式并填写 WebSocket 地址、模型和 WebSocket API Key。
- [ ] 如果 WebSocket API Key 留空，确认是否按预期复用 HTTP API Key。
- [ ] 点击悬浮按钮后进入监听状态。
- [ ] 说话时可以边说边在预览框看到文本变化。
- [ ] 停止录音后能在合理时间内返回最终结果。
- [ ] `realtime_chunk_ms` 调整后，实时响应没有明显异常。
- [ ] `websocket_final_wait_ms` 调整后，停止后的等待时间符合预期。
- [ ] 遇到 `socket is already closed` 等连接错误时，界面给出非阻塞提示。
- [ ] WebSocket 模式不会退回 HTTP API 一次性识别流程。
- [ ] 百炼 Paraformer 实时协议可以正常启动、上传音频和结束任务。

## 预览、复制与插入

- [ ] 识别结果先进入预览输入框。
- [ ] 用户可以手动编辑预览文本。
- [ ] 点击复制按钮后，剪贴板内容等于预览文本。
- [ ] 点击插入按钮后，文本可以输入到记事本。
- [ ] 点击插入按钮后，文本可以输入到浏览器输入框。
- [ ] 点击插入按钮后，文本可以输入到聊天软件输入框。
- [ ] 自动插入关闭时，识别完成后不会直接写入外部窗口。
- [ ] 自动插入开启且预览确认开启时，先显示预览再由用户确认插入。

## 翻译功能

- [ ] 语言设置为 `zh` 时，预览框显示“中翻英”入口。
- [ ] 语言设置为 `en` 时，预览框显示“英翻中”入口。
- [ ] 填写翻译 API 地址、模型和 API Key 后，可以生成翻译结果。
- [ ] 翻译结果不会自动覆盖原文，除非用户明确确认。
- [ ] 翻译 API Key 错误时，错误信息已脱敏。
- [ ] 翻译失败时不阻塞主窗口操作。

## 历史记录

- [ ] 每次有效识别完成后，结果会写入历史记录。
- [ ] 空文本不会写入历史记录。
- [ ] 历史记录按最新在前排序。
- [ ] 超过 `history_limit` 后，旧记录会被截断。
- [ ] 清空历史后，`data/history.json` 内容为 `[]`。
- [ ] `data/history.json` 不会被 Git 跟踪。

## 诊断与错误体验

- [ ] 诊断页可以显示首字延迟、收尾延迟、总耗时。
- [ ] 最近错误显示为脱敏后的用户可读信息。
- [ ] 没有麦克风权限时，界面提示原因和处理方向。
- [ ] 缺少本地模型依赖时，界面提示安装本地依赖。
- [ ] 缺少 HTTP API 依赖时，界面提示安装云端依赖。
- [ ] 缺少 WebSocket 依赖时，界面提示安装 WebSocket 依赖。
- [ ] 连续快速点击录音按钮时，不会启动多个录音任务。
- [ ] 关闭设置面板后，悬浮按钮仍可继续使用。
