# 离线语音输入器设计说明

## 产品定位

本项目面向七牛云比赛“语音输入法”方向，目标是在 Windows 桌面上提供一个可演示、可迭代的语音输入原型。它不是系统级 IME，而是一个悬浮输入助手：录音、离线识别、编辑文本，并把结果复制或插入到当前光标位置。

## 核心流程

1. 用户点击按钮或按全局快捷键开始录音。
2. 再次触发后停止录音，生成临时 WAV 文件。
3. `faster-whisper` 在本地 CPU 上转写中文语音。
4. 识别结果进入悬浮窗文本框，用户可以编辑、整理、复制或插入。
5. 最近输入内容写入本地历史记录。

## 技术边界

- 为保证短周期交付，不接入 Windows TSF/IME 内核。
- 默认使用剪贴板加 `Ctrl+V` 模拟输入，适配常见文本框。
- 第三方依赖在 README 中列明，原创部分集中在桌面交互、录音调度、识别封装和输入流程。
