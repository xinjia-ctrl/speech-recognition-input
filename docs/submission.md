# 比赛提交说明

## 仓库链接

报名阶段无需填写，议题发布后 24 小时内回到表单补充公开仓库链接。

## Demo 视频建议

视频建议控制在 2 到 4 分钟，覆盖以下内容：

1. 启动桌面悬浮输入器。
2. 使用快捷键或按钮开始录音。
3. 停止录音并展示本地离线识别结果。
4. 编辑和整理识别文本。
5. 复制或插入到记事本、浏览器输入框等外部应用。
6. 展示历史记录与设置页。

## 持续交付要求

- 每个功能阶段保持独立 commit。
- 如果使用 GitHub PR，PR 描述要写清楚实际变更。
- 不要在截止前一次性导入所有代码。
- README 必须列明第三方依赖，并说明原创实现范围。
